# user-needs-research

> 来源分类：**待确认** ｜ 导出批次：review

专为产品创新和设计打造的用户需求研究工具。通过六大维度（需求层级、痛点挖掘、用户分层、决策链路、消费动机、行为逻辑）进行系统化用户研究，帮助产品经理、设计师、创业者深度理解目标用户，发现创新机会。最终输出专业Word格式的研究报告，包含完整分析框架、洞察结论和行动建议。适用于新产品立项、功能优化、市场进入、用户增长等场景。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/user-needs-research        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/user-needs-research   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
